# TWSE Stock App

An Android application that displays stock information from the Taiwan Stock Exchange (TWSE) OpenAPI.

## Demo Video

[Watch Demo Video](https://youtu.be/WjwAXEc1N9E)

## Features

- Fetch stock data from TWSE OpenAPI.
- Display stock information using RecyclerView and Jetpack Compose (`ComposeView` in XML).
- Pull to refresh the stock list.
- Sort stocks in ascending or descending order.
- View detailed stock information.
- Show the closing price in red when it is above the monthly average, or green when it is below.
- Support portrait (single-column) and landscape (two-column) layouts.
- Include unit tests for `StockMapper` and `StockViewModel`.
